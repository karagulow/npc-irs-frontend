# Система управления гражданами

## Демо

[Открыть приложение](https://karagulow.github.io/npc-irs-frontend/)

## Функциональность

- Дашборд с общей статистикой.
- Просмотр списка граждан.
- Поиск и фильтрация граждан.
- Сортировка и пагинация таблицы.
- Просмотр профиля гражданина.
- Форма добавления нового гражданина с валидацией.
- Переключение светлой и тёмной темы.
- Адаптивный интерфейс.

## Технологии

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- Lucide React

## Запуск проекта

Склонировать репозиторий и установить зависимости:

```bash
git clone https://github.com/USERNAME/npc-irs-frontend.git
cd npc-irs-frontend
npm install
```

Запустить в режиме разработки:

```bash
npm run dev
```

Открыть в браузере:

```bash
http://localhost:5173/npc-irs-frontend/
```
